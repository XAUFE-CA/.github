## 01 / 关于学社 🌱

XCA（西安财经大学计算机学社）致力于建设一个**真诚、包容、和谐、热爱技术**的交流社区。我们重视平等交流、相互尊重与知识共享，欢迎不同学习阶段、不同技术方向的同学参与。

项目实践不限定技术栈，既面向实际需求，也支持技术探索。参与者可以加入现有项目，或提出新的项目构想，通过讨论与协作共同推进。

[浏览组织的公开仓库 →](https://github.com/orgs/XAUFE-CA/repositories)

## 03 / 如何参与 🥰

<table>
  <tr>
    <td width="33%" valign="top"><strong>💬 问题交流</strong><br><br>在相关仓库的 Issue 中反馈问题或提出建议，并提供必要的背景与说明。</td>
    <td width="33%" valign="top"><strong>🛠️ 参与实践</strong><br><br>根据自身基础与兴趣，参与文档完善、问题修复、测试补充或功能开发。</td>
    <td width="34%" valign="top"><strong>🤝 协作审查</strong><br><br>通过 Pull Request 提交修改，记录改动与验证结果，并根据审查意见完善内容。</td>
  </tr>
</table>

参与贡献不以独立完成项目为前提。文档修正、问题复现与使用反馈同样是有价值的贡献。
