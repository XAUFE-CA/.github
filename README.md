# XCA · 社区指南

XCA（计算机学社）围绕技术交流、知识分享与项目实践开展活动，致力于建设一个**真诚、包容、和谐、热爱**的交流社区。

## 从这里开始

| 你想做什么 | 前往 |
| :--- | :--- |
| 了解社区与项目方向 | [XAUFE-CA 组织主页](https://github.com/XAUFE-CA) |
| 查找感兴趣的公开项目 | [项目列表](https://github.com/orgs/XAUFE-CA/repositories) |
| 修正文档、提交代码或参与设计讨论 | [贡献指南](./CONTRIBUTING.md) |
| 了解社区交流约定 | [行为准则](./CODE_OF_CONDUCT.md) |

## 使用项目与反馈问题

- **开始使用**：进入具体项目仓库，阅读其 README、使用文档与版本说明。项目是否公开、提供哪些功能及如何使用，以对应仓库的实际内容为准。
- **反馈问题或建议**：请在对应项目仓库提交 Issue；报告与提案需要准备的信息见 [Issue 与 Pull Request 协作规范](./COLLABORATION.md#6-issue-与-pull-request-协作规范)。
- **发现社区文档问题**：可以在 [本仓库的 Issues](https://github.com/XAUFE-CA/.github/issues) 中反馈。

> [!WARNING]
> **安全问题请勿公开披露。** 发现潜在漏洞时，请先阅读对应项目的安全说明，通过其已公布的非公开渠道报告；通用说明见 [安全说明](./SECURITY.md)。

## 参与社区

欢迎不同学习阶段、不同技术方向的同学参与。你可以从一处文档修正、一次问题反馈或一个小改进开始，不必一开始就承担完整功能。

准备提交修改时，请先阅读 [贡献指南](./CONTRIBUTING.md)，并遵循目标项目已公布的要求。

[项目开发与协作规范](./COLLABORATION.md) 集中维护 AI 辅助协作、Git 提交、代码审查与 PR 协作等约定，具体规则及当前版本以该文档为准。

## 许可与复用

组织默认采用以下许可：

- **代码**：[MIT](./LICENSE)。
- **文字内容**：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，复用与改编时须署名 XAUFE-CA（XCA 计算机学社）并注明修改。

具体项目的使用与再分发条件，以对应仓库中的许可证及相关声明为准。
